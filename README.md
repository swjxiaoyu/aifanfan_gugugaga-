# 爱番番寻客宝企业数据采集（DrissionPage RPA）

一个基于 **DrissionPage** 的半自动 RPA 脚本：启动独立浏览器环境（持久化 Cookies），由你手动完成登录/搜索/定位到列表页后，脚本自动逐行采集企业信息与“可拨通”联系方式，并实时追加写入 CSV。

> 本仓库脚本面向你**已拥有合法访问权限**的后台页面使用。请遵守平台协议与当地法律法规，合理控制频率，避免对网站造成压力。

---

## 功能特性

- **独立浏览器用户数据目录**：使用 `ChromiumOptions().set_user_data_path('user_data')`，与主浏览器隔离且可保存登录态。
- **手动登录后继续**：启动后等待你在浏览器完成登录、搜索关键词并进入数据列表页，然后回车开始自动化。
- **逐行采集企业字段**：
  - 公司名
  - 法人代表
  - 注册资本
  - 成立日期
  - 行业
- **电话采集（保留原版核心逻辑）**：
  - 点击行内“极速联系”按钮
  - 只提取带 **“可拨通”** 标识的联系人条目
  - 多种选择器兜底提取手机号
  - 通过 **ESC** 关闭左侧抽屉并固定等待
- **实时落盘**：每处理一行立刻 `append` 写入 CSV，便于中断后保留已采集数据。
- **翻页与随机等待**：翻页后随机等待 5～8 秒，降低风控风险（电话按钮点击前目前为固定短等待，可按需自行加随机等待）。

## 核心实现说明（便于二次维护）

### 1）页面行定位（表格结构）

脚本按表格行遍历企业卡片，默认选择器为：

- `SELECTORS['company_card'] = 'tag:tr@@class:el-table__row'`

如果页面从“表格行”变回“卡片 div”，你只需要替换为实际容器选择器即可。

### 2）基础字段提取：`extract_by_label()`

法人/注册资本/成立日期/行业使用同一套通用逻辑：

- 先在当前行内找到包含标签文本的元素（如 `text:法人代表`）
- 再取该标签元素的 **next() 兄弟节点** 作为值

对应配置项：

- `label_legal = text:法人代表`
- `label_capital = text:注册资本`
- `label_date = text:成立日期`
- `label_industry = text:行业`

> 若页面结构改为“标签和值不在兄弟节点关系”，你可能需要改造为：取父级容器再 `.eles()`、或根据更稳定的 `data-*` 属性定位。

### 3）电话采集：只抓“可拨通”

电话详情抽屉打开后，脚本用 XPath 只筛选包含“可拨通”文本的 `.contact-item`：

- `xpath://div[contains(@class, "contact-item")][.//span[text()="可拨通"]]`

然后对每个 item 尝试多种方式提取号码（兜底策略）：

1. `.text.f-1`
2. `tag:span@@class=text f-1`
3. `xpath:.//span[contains(@class,"text") and contains(@class,"f-1")]`
4. `.text`

关闭抽屉方式：

- `page.actions.type(Keys.ESCAPE)`（按 ESC）
- 并固定等待 4 秒（不强制等待抽屉消失）

## 常见问题（FAQ）

### Q1：运行后提示“未找到数据行”

- **原因**：当前页面不是数据列表页、列表未加载完成、或页面结构/类名变更。
- **处理**：用浏览器开发者工具确认企业列表每行的真实 DOM，再修改 `SELECTORS['company_card']`。

### Q2：点击“极速联系”后拿不到号码（一直“未找到可拨通联系人项”）

- **原因**：详情抽屉中没有“可拨通”标签、或“可拨通”的 DOM 结构/文本变更。
- **处理**：
  - 先把 XPath 中 `span[text()="可拨通"]` 的文本改成页面实际显示的词
  - 或直接放宽筛选逻辑：改为抓取所有 `.contact-item`（需自行权衡数据质量）

### Q3：频繁触发风控/页面卡住

- 增大翻页等待（如 8～12 秒）
- 点击“极速联系”前加随机等待（当前脚本未显式加，可自行增加）
- 降低并发（本脚本是单线程顺序执行）
